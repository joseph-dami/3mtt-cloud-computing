## Selected Azure Region

The region I selected for my Azure resources is:  
**South Africa North**

### Reason for selection:
- Low latency based on proximity to Nigeria
- Better performance due to geographic closeness
- Availability of required Azure services in the region


## Shared Responsibility Model

The Shared Responsibility Model in Azure defines how responsibility is divided between Microsoft and the customer (me).

The resource deployed was an Azure Storage Account.

### Applied to my Storage Account:
In the deployed Storage Account, Microsoft ensures the infrastructure is secure and available, while I am responsible for controlling who can access the data and how it is used.
